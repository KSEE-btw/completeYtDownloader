# ytgrab 0.3.6

The popup no longer looks frozen while a video is being read.

## Fixed

- **Reading a slow video no longer freezes everything else.** The helper
  handled one request at a time, so while a `list_formats` probe was running
  (yt-dlp can take a while on a live stream, a premiere, or a video that needs
  sign-in), the popup's version check — and every other request — waited behind
  it. Both then looked stuck: "Reading available formats…" *and* the version
  still "checking…". Probes and the download hand-off now run on their own
  thread, so the version check and other commands answer immediately.
- **Reads are bounded.** A probe now gives up after 90 seconds with a clear
  message (down from 150) instead of hanging, and names live / age-restricted
  videos as the usual cause.
- **No more silent spinner.** If the helper doesn't answer the version check
  within 20 seconds the popup says so, and a probe that is still working
  explains itself after 25 seconds.

## Notes

- No new commands or settings.
- If a read still fails, it is almost always the video (live, premiere, or
  sign-in required) rather than ytgrab; the message now says so.

## How to get it

Run `ytgrab update`, or install this bundle. The extension updates itself.
