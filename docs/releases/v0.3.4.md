# ytgrab 0.3.4

Pick your download folder with the mouse, and ytgrab remembers it.

## New

- **A folder picker.** The **Save to** bar in the popup now has a **…** button
  that opens the normal Windows folder chooser — no more typing a path by hand.
  The choice is saved as your default and shown next time.
- **The queue window got the same thing.** A **Save to** bar at the top shows
  the current folder, and **Change…** opens the picker there too. Handy when
  the popup has already closed.
- Both places share one setting (`outdir`), so changing it in either updates
  where downloads land.

## Notes

- The picker is opened by the ytgrab helper rather than the browser page: a web
  page cannot read real filesystem paths. If you open it from the popup, the
  popup may close while the chooser is up — the folder is still saved, and the
  popup shows it the next time you open it.
- Cancelling the chooser leaves your setting untouched.

## How to get it

Run `ytgrab update`, or install this bundle. The extension updates itself.
