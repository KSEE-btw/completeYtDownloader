# ytgrab 0.3.5

Folder changes now stick everywhere, immediately.

## Fixed

- **Changing the folder in the queue window now reaches the browser popup.**
  The helper cached `config.json` for its whole lifetime, so when the queue
  wrote a new **Save to** folder, the popup kept showing — and downloading to —
  the old one. The helper, the queue and the CLI are separate processes; each
  now re-reads the config the moment the file changes, so all three agree.
- **Downloads follow the current folder.** The popup used to attach its own
  copy of the folder to every download, which could override a newer choice.
  Downloads now use the live setting, so a folder changed anywhere is honoured.

## Notes

- No new commands or settings — this is a correctness fix on top of 0.3.4.
- If your popup still shows an older folder than the queue, close and reopen
  the popup; it refreshes on open.

## How to get it

Run `ytgrab update`, or install this bundle. The extension updates itself.
