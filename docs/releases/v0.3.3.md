# ytgrab 0.3.3

Video-only picks no longer land silent.

## What's fixed

- **A picked format that has no audio now gets the best audio muxed in.** Some
  entries in the format list carry video only, with no sound of their own.
  Choosing one used to produce a silent file. ytgrab now downloads the best
  available audio track alongside the video and lets yt-dlp mux the two into a
  single file as one task, so the finished download always has both streams.

  - Applies to every quality you pick explicitly, at any resolution.
  - No effect on formats that already carry audio, or on the "Auto" entries
    (those already merged video + audio).
  - If a video genuinely has no audio track, it downloads as before.

## New

- `ensure_audio` setting (default `true`). Turn it off with
  `ytgrab config ensure_audio false` to download video-only picks as-is.
- The format list now flags a video-only choice (`audio+`) and says the best
  audio will be muxed in.

## Notes

- The added track is the highest-quality audio yt-dlp finds (usually Opus).
  Muxing it with an H.264/MP4 video yields an MKV, so the usual conversion step
  turns the result into a Premiere-ready MP4 (audio re-encoded, video copied).
  With conversion turned off, the file lands as the muxed MKV.

## How to get it

Run `ytgrab update`, or install this bundle. The extension updates itself.
