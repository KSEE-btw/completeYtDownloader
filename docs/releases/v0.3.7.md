# ytgrab 0.3.7

See at a glance which video streams already carry audio.

## New

- **A speaker icon in front of every video source.** In the format list, each
  video entry now starts with a small glyph:
  - &#128266; **video + audio** — the stream already has sound.
  - &#128263; **video only** — no audio in the stream; ytgrab pulls the best
    audio track and muxes it in for you.
- **Audio-only sources get no icon**, exactly as asked — the marker only means
  something for video.

## Notes

- A Firefox `<select>` can only hold text, so the marker is a speaker glyph
  rather than a picture. It shows in both the popup and the in-page panel.
- The hint under the list already explains the video-only case ("audio+"), and
  the tooltip on a video-only row now says the audio track will be added.

## How to get it

Run `ytgrab update`, or install this bundle. The extension updates itself.
