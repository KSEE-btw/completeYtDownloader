# ytgrab 0.3.1

Fixes yt-dlp / ffmpeg being reported as "not found on PATH" even though they
were just installed.

## What's fixed

- **Tool discovery no longer depends on Firefox's environment.** The helper is
  launched by Firefox and inherited the PATH Firefox had when it started, so
  yt-dlp / ffmpeg installed after that point -- typically by `setup.ps1` via
  winget, or by adding a folder with `setx` -- were reported as missing even
  though a brand-new terminal found them fine. The helper now also reads the
  saved user and machine PATH straight from the Windows registry, so downloads
  work right after installing the tools, with no browser restart required.

- The "not found on PATH" message shown in the page now suggests a full
  Firefox restart when the tools really are missing, instead of a dead end.

## How to get it

Install this bundle, or run `ytgrab update` if you already have 0.3.0. The
extension updates itself automatically afterwards.

## Under the hood

`ytgrab_core._which()` now merges the inherited PATH with the persisted
`HKCU\Environment\Path` and machine `Path` (Windows only), deduplicated, before
falling back to the well-known default locations (`WinGet\Links`,
`WindowsApps`, `C:\ffmpeg\bin`).
