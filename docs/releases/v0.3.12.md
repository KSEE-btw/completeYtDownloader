# ytgrab 0.3.12

The **editor pack**: grab just the part of a video you need, and hand Premiere a
file that behaves on a timeline.

## What's new

**Clip range.** The popup grows a **Clip** row — a start and an end — so a
download can cover just that stretch:

```
1:30  →  2:15
```

Fill in either side on its own, write it as `1:30`, `0:01:30` or plain seconds,
and leave both blank for the whole video. yt-dlp fetches only the fragments that
cover the range, so a 45-second clip of a two-hour stream takes seconds instead
of hours — and a keyframe is forced at each cut so the in and out points land
exactly where you asked.

**Constant FPS.** Phone recordings and screen captures are often *variable*
frame rate, which is what makes a long clip drift out of sync against its audio
by the end. Tick **Constant FPS** and the video is rebuilt at a constant rate —
the source's own rate, so 29.97 stays 29.97; only the variance goes. Footage
that is already constant is left untouched.

**48 kHz audio.** Editing tools mix at 48 kHz. Tick **48 kHz audio** and the
audio is re-encoded at that rate, with the video stream-copied, so nothing else
about the file changes.

## Notes

- The clip range is applied *during* the download (`--download-sections`), so it
  works with conversion switched off, and it is the cheap way to pull a small
  piece out of a long video.
- **Constant FPS** and **48 kHz audio** are explicit asks, so they take priority
  over the "already Premiere-compatible" shortcut. Only the part that needs work
  is touched: a 48 kHz request on otherwise-compatible footage copies the video
  and rewrites only the audio, and an already-48 kHz source is not touched at
  all.
- A clip time that cannot be read is refused in the popup before anything is
  queued; in the config it simply means "no bound".
- `clip_start`, `clip_end`, `force_cfr` and `audio_48k` are ordinary settings, so
  `ytgrab config clip_start 2:00` sets a standing default and the popup opens
  with it filled in.

## How to get it

Run `ytgrab update`, or install this bundle.
