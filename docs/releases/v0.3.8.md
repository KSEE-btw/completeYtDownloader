# ytgrab 0.3.8

The download queue window got a real look: **Breeze**, KDE Plasma's default
theme.

## New

- **Breeze styling for the queue window.** Soft light-grey window, a white list
  view, flat 1px hairlines instead of chunky borders, and Plasma's signature
  `#3daee9` blue for accents, the progress bar and hover states.
- **A toolbar header.** The title row is now a proper toolbar strip — a small
  blue arrow, "ytgrab queue", a live summary ("1 downloading · 2 waiting"), and
  flat Breeze buttons on the right, separated from the list by a hairline.
- **Status stripes.** Every item is a white card with a 4px stripe down the left
  that tells you its state at a glance: grey (waiting), **blue** (downloading),
  green (done), red (failed). While a card is actually downloading its border
  lights up blue.
- **Coloured progress.** The bar is blue while downloading, green when the file
  is done and red when it failed, on a soft grey trough.
- **Breeze scrollbar.** A slim grey thumb instead of the default Tk widget.
- **Better font fallback.** Picks Noto Sans if you have it (KDE's default
  face), else Cantarell, Segoe UI, DejaVu Sans.

## Notes

- Same window, same buttons, same behaviour — only the look changed.
- Downloads, the queue, the popup and the in-page panel are untouched.

## How to get it

Run `ytgrab update`, or install this bundle.

Prefer a dark queue window? Say the word and this becomes **Breeze Dark**
(`#31363b` window, `#232629` view, same blue) — it is a palette swap.
