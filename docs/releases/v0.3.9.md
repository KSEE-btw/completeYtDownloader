# ytgrab 0.3.9

The queue window has a **light / dark toggle**, and it remembers what you pick.

## New

- **A Dark ⁄ Light button** in the queue toolbar. In light mode it reads
  "&#9790; Dark"; click it and the whole window flips to Breeze Dark, and the
  button becomes "&#9728; Light" to flip back. The change is instant and saved.
- **The choice sticks.** It is written to `ui_theme` in your config
  (`~/.config/ytgrab/config.json`), so the queue opens the way you left it.
- **Sensible first run.** With no choice saved, the queue follows your
  **Windows app theme** — if Windows is in dark mode, the queue starts dark,
  and vice-versa. (On your machine that means it starts dark already.)

## The two palettes

| | Light (Breeze) | Dark (Breeze Dark) |
|---|---|---|
| window | `#eff0f1` | `#31363b` |
| card | `#ffffff` | `#232629` |
| text | `#232629` | `#eff0f1` |
| hairline | `#c9ced3` | `#1b1e20` |
| accent | `#3daee9` | `#3daee9` |

The status stripes (grey / blue / green / red), the coloured progress bars and
the `#3daee9` accent are the same in both modes.

## Also fixed

- **A harmless error after quitting.** A scheduled refresh could fire once the
  window was already gone and log `invalid command name "..._tick"`. The
  pending refresh is now cancelled on quit.

## Notes

- Only the queue window changed; the popup, the in-page panel and downloads are
  untouched.
- Advanced: set `"ui_theme"` to `"light"`, `"dark"` or `"auto"` by hand — the
  toggle writes `"light"`/`"dark"`.

## How to get it

Run `ytgrab update`, or install this bundle.
