# completeYtDownloader 0.3.15

This release is a **rename**, not a feature change. Downloads, formats, the
queue and the editor pack all behave exactly as they did.

## The name

The project and its repository are now called **completeYtDownloader** (the
repository was `youtubeDownloaderXConverter`, and the program inside it was
called `ytgrab`). Everywhere you *read* the name it now says
completeYtDownloader: the add-on entry in `about:addons`, the popup header, the
queue window title, the installer summary and the README.

The add-on's own update manifest moved with the rename, so Firefox keeps finding
new versions by itself — you do not have to reinstall anything.

## What deliberately kept its old name

Some names are baked into copies that are already installed on your disk, and
into Firefox itself, so they are frozen:

- the `ytgrab` command, `ytgrab.exe` and `ytgrab-host.exe`
- `%LOCALAPPDATA%\ytgrab` and `~/.config/ytgrab` — your settings, queue and
  version record
- the registry key that registers the helper with Firefox
- the add-on ID `ytgrab@kunal.local`

So: anything you *read* is completeYtDownloader, anything you *type* is still
`ytgrab`.

## Nothing to do

This installs like any other update. `ytgrab update` in a terminal and
Firefox's own "Check for updates" in `about:addons` both keep working, and
nothing about an existing install breaks.
